# DLE-Zenless

I'm making this project mainly for fun. I wanted to see more variety among DLE-style games for Zenless Zone Zero, so I decided to create my own version with several different game modes.

## Game Modes

### Classic
The classic mode probably doesn't need much of an introduction.
Enter an Agent's name and see which of their attributes match the mystery Agent and which don't. Use the clues to narrow down the possibilities until you find the correct Agent.

### Endless Mode
For those who feel like one puzzle a day just isn't enough.
Keep guessing Agents without being limited to a single daily puzzle.

### Pixel Silhouette
In this mode, you have to guess the Agent from their pixelated silhouette — or rather, from the mosaic you see in front of you.
Splash Art
In this mode, you have to identify the Agent from a fragment of their Splash Art.

### Bangboo
A mode where you have to guess the Bangboo from a set of emojis.

# DLE Zenless
Этот проект я делаю в первую очередь для души. Мне хотелось больше разнообразия среди DLE по Zenless Zone Zero, поэтому я решил сделать свой вариант с несколькими разными режимами.

## Режимы

### Классика
Режим, который в представлении особо не нуждается.
Вводите имя агента и смотрите, какие его характеристики совпадают с загаданным персонажем, а какие — нет. Используя полученные подсказки, постепенно сужаете круг вариантов, пока не угадаете загаданного агента.

### Бесконечный режим
Для тех, кому одной загадки в день недостаточно.
Можно продолжать угадывать агентов без ограничения одной ежедневной загадкой.

### Пиксельный силуэт
Режим, в котором вам нужно угадать агента по пиксельному силуэту — или, скорее, по той мозаике, которую вы видите перед собой.

### Splash Art
В этом режиме вам нужно определить агента по фрагменту его Splash Art.

### Банбу
Режим, в котором нужно угадать Банбу по набору эмодзи.
